# Client photos

| Path                           | Used for                               |
| ------------------------------ | -------------------------------------- |
| `cover.jpg`                    | Cinematic cover (full-bleed, portrait) |
| `families.jpg`                 | "With Our Families" couple photo       |
| `story.jpg`                    | "Their Story" photo                    |
| `party/member-1.jpg` … `-6`    | Wedding party portraits (3:4)          |
| `registry/item-1.jpg` … `-4`   | Registry item images (square)          |

Paths are set in `src/content/wedding.ts`. Any missing file shows a labeled
placeholder, so you can swap them in one at a time.
