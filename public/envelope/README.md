# Envelope layers

The intro uses a black envelope sealed with a gold mirror-acrylic crest. Each
layer is drawn in code until a transparent PNG with the matching name exists
here:

| File             | What it is                                              | Shape |
| ---------------- | ------------------------------------------------------- | ----- |
| `noir-body.png`  | The envelope's front (pocket folds), opaque             | 407 : 275 (about 1.48 : 1) |
| `noir-flap.png`  | The V flap, hinge on its top edge, point bottom-centre  | 407 : 154 (about 2.64 : 1) |
| `noir-crest.png` | The gold crest that sits on the flap's point            | 10 : 7 |

The body and flap PNGs are stretched to their slots, so export them at those
shapes; the crest is fitted inside its slot.
